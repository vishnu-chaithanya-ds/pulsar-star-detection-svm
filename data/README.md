# Data

Place `pulsar_stars.csv` in this folder before running the notebook.

- **Dataset:** "Predicting a Pulsar Star" (pulsar candidates from the HTRU2 survey), available on Kaggle and the UCI Machine Learning Repository.
- **Size:** 17,898 rows × 9 columns (8 continuous features + `target_class`).
- Check the dataset's licence before re-uploading the CSV to this repository. If unsure, keep the file out of Git and link to the source instead.
